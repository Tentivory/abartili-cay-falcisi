# 🍵 Abartılı Çay Falcısı

## Dünyanın En Ciddi, En Abartılı, En Bilimsel Çay Falcısı

Bu repository, insanlık tarihinin en önemli icadı olan **çay**ın, en önemli fal yöntemi olan **fal** ile birleştiği eşsiz bir kesişim noktasıdır.

### Neden Bu Program?

- Çünkü normal falcılar yeterince abartılı değil.
- Çünkü çay yaprakları gerçekten konuşur (biz de dinliyoruz).
- Çünkü hayat zaten saçma, bari falı da saçma olsun.
- Bilimsel olarak kanıtlanmış saçmalık sertifikası vardır (sertifika kayboldu ama var).

### Nasıl Kullanılır?

```bash
python cay_falcisi.py
```

Program sizden adınızı soracak, sonra çay yapraklarının sırrını açıklayacak. Her çalıştırmada farklı bir saçmalık.

### Özellikler

- %100 gerçek çalışan Python kodu
- Rastgele absürt fal tahminleri
- Dramatik bekleme efektleri
- Bilimsel saçmalık garantisi
- Çay içmeden de çalışır (ama içerseniz daha iyi olur)

### Uyarı

Bu programın verdiği fallar gerçek değildir. Gerçek fal için gerçek bir falcıya gidin. Veya gerçek bir çay için çay ocağına gidin. Bu program sadece eğlenmek içindir. Ciddiye almayın. Ama yine de ciddiye alın, çünkü çay ciddi bir iştir.

### Katkıda Bulunma

Yeni absürt fallar eklemek isterseniz pull request açın. Kabul edilme garantisi yoktur ama okuruz.
